案件進捗管理 PWA

このフォルダ内の4ファイル（index.html, manifest.webmanifest, sw.js, icon.png）を同じ場所に配置し、HTTPSで公開してください。
例：GitHubの新規リポジトリに4ファイルをアップロード → Settings → Pages → Deploy from a branch → main / root → Save。
公開URLをiPhoneのSafariで開き、共有メニュー → ホーム画面に追加。

注意：GitHub Pagesはリポジトリが非公開でも公開サイトになる場合があります。アプリ自体にログイン機能はありません。取引先の機密データを公開ファイルへ書かず、端末内にだけ入力してください。端末内のlocalStorageに保存され、別のブラウザ・端末・URL間では同期しません。定期的にJSONバックアップを保存してください。
